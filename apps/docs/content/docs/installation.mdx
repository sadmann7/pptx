title: Installation
description: Install @diceui/pptx and its peer dependencies.
---

## React

```package-install
@diceui/pptx
```

`react` and `react-dom` (v18 or v19) are peer dependencies and must be installed separately if not already in your project.

## Parser only

If you don't use React and only need the OOXML parser and renderer:

```package-install
@diceui/pptx-parser
```

The parser has no framework dependency. It runs in any modern browser environment that supports the Web Crypto API and dynamic imports.

## Requirements

| Requirement | Version                                   |
| ----------- | ----------------------------------------- |
| React       | 18 or 19                                  |
| TypeScript  | 5.0+ (optional but recommended)           |
| Browser     | Evergreen (Chrome, Firefox, Safari, Edge) |

The library is ESM-only (`"type": "module"`). It does not ship a CommonJS build.
